# MetisJean Clarity

Build a Premium MetisJean Website — Match the Reference Video Exactly

Build a complete, production-quality responsive website for MetisJean.

I have provided two reference files:

Metis Jean Brand Guidelines PDF — this is the source of truth for brand identity, colors, typography, logo treatment, messaging, photography direction, and visual language.

Reference screen-recording video — this is the source of truth for the website's visual layout, spacing, composition, navigation style, rounded container treatment, animation, and overall interaction feel.

The website should feel like a premium global technology transformation / intelligent automation consultancy.

Do NOT create a generic AI SaaS landing page.

Do NOT use a typical startup template.

The result should feel editorial, sophisticated, minimal, calm, intelligent, and highly polished.

6. HERO PARTICLE ANIMATION

This is critical.

The right side of the hero must contain an animated blue particle visualization inspired directly by the supplied reference video.

Do NOT replace it with:

a stock image

a generic AI brain image

a gradient blob

a static SVG circle

a random 3D object

Create an actual animated particle system.

Use Three.js or a performant HTML Canvas/WebGL implementation.

The particle visualization should:

consist of thousands of tiny points

use primarily MetisJean Dodger Blue #0b90f4

have subtle variations in blue opacity

form an organic spherical / cloud-like structure

continuously morph

subtly rotate

have fluid movement

look intelligent and data-driven

remain elegant and restrained

not look like a gaming effect

The animation should resemble a living field of data.

The particles should continuously reorganize their positions, creating subtle morphing patterns.

Use:

THREE.Points

BufferGeometry

PointsMaterial

procedural noise / simplex noise

subtle rotation

controlled particle opacity

easing

Target 60fps where possible.

The animation should begin automatically.

Add prefers-reduced-motion support so users who disable motion receive a calm static version.

On mobile, reduce particle count for performance.
